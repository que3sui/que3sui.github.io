ABOUT

中科大在读，AI Agent 方向。关注 LLM 应用、Coding Agent 与推荐系统——教机器做事，顺便观察它们怎么学。

喜欢把想法做成能跑的小东西：黑客松 48 小时搭出的「找搭子」、把论文读成知识库的 InsightMiner、会从情绪碎片里找线索的「情绪荒原」、重构自我叙事的 GeneEdit。有的已经跑通，有的还在跑。

最近在折腾知识工程：让 Agent 替我读论文、养 Wiki、做健康体检——建木、知识谱系和 Bridge 思维桥接器，都是「把学习外包给 AI，再把判断力收回来」的尝试。

平时上课做研究，周末折腾一个叫「蜗壳进阶联盟」的学生组织——让喜欢折腾的人凑在一起折腾。
